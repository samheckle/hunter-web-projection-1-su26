## Including Code

There are a couple different ways to include code:

- inline code using `<head>`

```
this is a code block for more than one line of code
we wrap the code block in triple `
```

Specify language in code block:

```html

<span class="blue"> this is blue text </span>

```

```css
.blue {
	background-color: blue;
}
```

`[text to be linked](https://url.com)`
